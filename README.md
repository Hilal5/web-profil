## ⚙️ Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/Hilal5/web-profil.git
```

### 2. Masuk ke Directory

```bash
cd web-profil
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Development Server

```bash
npm run dev
```

Kemudian buka:

```text
http://localhost:3000
```

---

## 🏗️ Build for Production

Untuk membuat production build:

```bash
npm run build
```

Kemudian jalankan:

```bash
npm start
```
